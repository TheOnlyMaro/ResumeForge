# Resume Forge

Local-first resume tailoring tool for rapidly generating targeted resumes from a reusable master CV database.

## Features
- Multiple resume variants
- Drag-and-drop section ordering
- Toggle sections/items quickly
- Local JSON persistence
- PDF export
- Inline text formatting and links with `*bold*`, `_italics_`, and `&link(text, url)`
- Harvard-style resume template

## Tech Stack
- React
- Vite
- Tailwind
- LocalStorage

## Motivation
Tailoring resumes repeatedly is slow and repetitive.
Resume Slicer focuses on maintaining one structured master CV and generating specialized resumes efficiently.
